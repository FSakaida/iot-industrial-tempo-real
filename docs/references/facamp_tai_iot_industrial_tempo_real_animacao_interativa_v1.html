7. Criando PostgreSQL + TimescaleDB

CREATE EXTENSION IF NOT EXISTS timescaledb;

CREATE TABLE assets (
  id VARCHAR(60) PRIMARY KEY,
  name VARCHAR(120) NOT NULL,
  production_line VARCHAR(80) NOT NULL,
  criticality SMALLINT NOT NULL CHECK (criticality BETWEEN 1 AND 5)
);

CREATE TABLE sensors (
  id VARCHAR(80) PRIMARY KEY,
  asset_id VARCHAR(60) NOT NULL REFERENCES assets(id),
  sensor_type VARCHAR(40) NOT NULL,
  unit VARCHAR(20) NOT NULL,
  sample_seconds INTEGER NOT NULL CHECK (sample_seconds > 0)
);

CREATE TABLE telemetry (
  time TIMESTAMPTZ NOT NULL,
  sensor_id VARCHAR(80) NOT NULL REFERENCES sensors(id),
  value DOUBLE PRECISION NOT NULL,
  quality SMALLINT NOT NULL DEFAULT 100,
  seq BIGINT,
  PRIMARY KEY (sensor_id, time)
);

SELECT create_hypertable(
  'telemetry','time',
  chunk_time_interval => INTERVAL '1 day'
);

CREATE INDEX telemetry_sensor_time_idx
ON telemetry(sensor_id, time DESC);
Hypertable: o aluno continua usando SQL, enquanto o TimescaleDB organiza os dados temporais em chunks gerenciáveis.

8. Consultas para tempo real e histórico

Último valor por sensor

SELECT DISTINCT ON (sensor_id)
       sensor_id, time, value, quality
FROM telemetry
ORDER BY sensor_id, time DESC;

Agregação por minuto

SELECT time_bucket('1 minute', time) AS minute,
       sensor_id,
       avg(value) AS avg_value,
       max(value) AS max_value
FROM telemetry
WHERE time >= now() - INTERVAL '2 hours'
GROUP BY minute, sensor_id
ORDER BY minute;

Hot

7 dias de detalhe na frequência original.

Warm

90 dias com agregação por minuto/5 minutos.

Cold

Agregados horários/diários para histórico e analytics.

12. Segurança, observabilidade e recuperação

Rede OT x IT

Não exponha sensores/CLPs diretamente à Internet. Use gateway e segmentação.

MQTT

TLS, autenticação, ACL por tópico e credenciais por gateway.

Banco

Conta de aplicação com menor privilégio; administração separada.

Observabilidade

Monitore msg/s, backlog, lag, queries lentas, disco e p95 da API.

Backup/Restore

Defina RPO/RTO e teste restauração regularmente.

Edge buffer

Retenha temporariamente dados quando backend/rede ficarem indisponíveis.
